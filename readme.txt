Sukkah AR package
=================

Files:
- index.html
- sukkah.glb

How to use:
1. Upload both files to an HTTPS static host such as Netlify.
2. Open the site URL on your phone.
3. Android: use Chrome.
4. iPhone/iPad: use Safari.
5. Wait for the model to finish loading.
6. Tap "View in your room".

Notes:
- This package uses the newly uploaded GLB as-is, without additional quality reduction.
- On Apple devices, AR Quick Look support still depends on device memory and browser support.
- If iPhone/iPad still struggles, the next proper step is creating a dedicated optimized USDZ file.
